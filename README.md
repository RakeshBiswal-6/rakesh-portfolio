# Rakesh Biswal — 3D Personal Developer Portfolio

An immersive, minimal luxury 3D personal portfolio website built with React, Three.js, React Three Fiber, GSAP, and Tailwind CSS.

## 🚀 Live Website
- **Repository**: [https://github.com/RakeshBiswal-6/rakesh-portfolio](https://github.com/RakeshBiswal-6/rakesh-portfolio)

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion
- **3D & WebGL**: Three.js, React Three Fiber, Drei, GSAP
- **Icons**: Lucide React, Custom Brand SVGs
- **Deployment**: Vercel & GitHub Pages support

## 💻 Local Setup & Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Create production build
npm run build

# Preview production build locally
npm run preview
```
